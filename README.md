# 台风探秘 · 地球实验室

一个可以直接在浏览器里玩的中文台风科普网站。

**在线体验：https://brian-jiangz.github.io/typhoon-explorer/**

## 可以玩什么

默认打开 **杜苏芮（2023）六小时历史天气检验**：自动载入 JMA 的真实起点，显示按天气场计算的绿色路径与独立的金色最佳路径。副高显示实际 500 hPa 等高线，随历史天气变化；不能手动拖动。此案例资料到 2023 年 7 月 31 日结束，不向缺测未来外推。左上“背景”可切回全球多年平均沙盘，继续自由选点、调整副高。


- **热带气旋实验**：支持北半球多海域，可通过“大西洋”“美国附近”等入口转地球并轻点海面；在同一块面板选择海面起点、初始云团、月份及环境条件，并拖动或用按钮摆放副高。选好海面起点后即可开始，无需额外勾选副高确认。开始前可调整副高；开始后隐藏地球上的两个副高操作文字框，保留副高轮廓。开始后锁定全部实验设定，暂停、回看、重播不解锁；点击“重新设置”清除记录并重新开放选点与条件。初始观察窗口为 15 天，播放到窗口末尾自动延长 5 天并继续，不需再次点击；支持“+1天”按实际模型时间快进，默认 8× 播放，可选 1/2/4/8/16×，每秒对应 2/4/8/16/32 模拟小时，改变播放节奏不改变风场或路径；不强制登陆或消散，近岸热力资料缺测时仍按有效风场移动，并暂存海上强度；引导风缺测时停止并说明原因。进度条以观察窗口为范围，只能回看已计算部分。九项条件直接展开，右侧详情与图层始终可见。
- **台风结构**：默认展示可旋转的三维剖面，包含高耸眼墙、贯通风眼、高空云盾和起伏的螺旋雨带。剖面由同一套三维云体求交生成并跟随相机；可切换“立体看”“剖开看”、旋转缩放及复位。四种颜色区分低层流入、眼墙上升、高空流出和眼内下沉；不提供“从上看”入口，垂直比例和气流速度仅为教学示意。
- **知识挑战**：题库共25道，覆盖结构、形成条件、路径、登陆减弱和避险。每次打开随机抽5道，轮内不重复；点击“刷新抽题”或完成后的“重新随机抽5题”重新抽取并清空本轮进度，避免整套题目与上一轮完全相同。保留找眼墙、操作副高、多选防台风准备等交互题，以及醒目的对错提示。

## 使用方式

打开上面的在线链接即可。也可以下载仓库，直接打开 `index.html`；资源均保存在本地，无须 API 密钥或额外构建。三维效果需要浏览器支持 WebGL；知识挑战使用平面示意图。

## 数据与科学边界

“多年平均沙盘”读取 NOAA ERSSTv5 和 NCEP–NCAR 再分析的 1991–2020 月平均气候背景，并以 tcpyPI / BE02 温湿剖面算法计算热力强度上限。可切换月份，沿途海温、700 hPa 湿度、200–850 hPa 风差和引导风随位置变化；不再用纬度单独决定降温。手动修改会标为假设试验。

热力上限有公开物理依据；组织度、增长/衰减时间尺度、暖水深度敏感性及气压估算仍是未校准的简化关系，强度过程没有完成历史台风回报验证。路径目前仅检验了下述单一案例。主实验固定采用 850–200 hPa 深层气候引导，不随强度自动换层，这是教学假设而非浅薄弱扰动的真实路径模型；根据副高调整对气候引导风作局部空间重排，图上箭头与路径使用同一风场；副高默认边界仍为未校准示意；挑战页仍使用独立的理想化副高及示例生命周期。三维云系仍为视觉示意，地表是静态合成影像。网站不能预测真实台风或实际登陆位置。

方法、输入文件校验和及软件版本见 [数据与模型说明](assets/SOURCES.md)、[数据清单](assets/climate-manifest.json) 和 [知识挑战依据](assets/LEARNING-SOURCES.md)。背景重建脚本为 [scripts/build-climate.py](scripts/build-climate.py)，需要 NumPy、xarray、netCDF4 和 tcpypi==1.4；网页运行不需要这些依赖或 API 密钥。

## 杜苏芮历史案例

同一起点（2023-07-21 00 UTC，13.8°N、133°E），与 JMA 最佳路径六小时时刻对照至 228 小时：

| 指标 | 月平均背景 | 六小时天气 | JMA / 官方参考 |
|---|---:|---:|---:|
| 平均位置误差 | 588 km | 116 km | — |
| 前 120 小时平均移速 | 9.2 km/h | 17.9 km/h | 12.1 km/h |
| 福建大陆登陆时间 | 观察期内未登陆 | 7月28日04:15 北京时间 | 7月28日09:55 北京时间（CMA） |

六小时方案路径和登陆改善，但早期平均移速偏快。再分析是事后重建、包含风暴信息；单案例不能代表预报能力或其他台风的精度。未乘移速系数、未强制登陆、未沿最佳路径移动。粗海岸线导致登陆判定误差，不能把几十公里差距理解为该精度已验证。完整方法、原始链接、敏感性结果和再现命令见 [历史天气说明](assets/WEATHER-SOURCES.md)、[原始资料清单](assets/weather-manifest.json)、[完整检验结果](assets/weather-validation.json)。

## 检查与发布

运行 `node checks/verify-formation.cjs` 可检查选点、逐步生长、衰减与记录回看；运行 `node checks/verify-ridge.cjs` 可复查引导方向、单位换算、控制独立性、路径积分和陆上衰减的一致性。有原始缓存和上述 Python 依赖时，还可以运行 `python scripts/verify-climate.py --cache <原始资料目录>` 独立复查温湿单位、PI 和引导风积分。这些检查不代表真实预报精度。

交互流程检查为 `checks/verify-timescale.cjs`、`checks/verify-setup.cjs`、`checks/verify-quiz.cjs` 与 `checks/verify-structure.cjs`，需要 Node.js 和 `linkedom`（可由外部测试环境提供）。它们覆盖统一设置、开始门槛、运行锁定、重新设置与25题题库、随机五题和刷新抽题，使用模拟渲染器，不替代实际浏览器的视觉检查。

GitHub Pages 从 `main` 分支根目录发布。后续推送到 `main` 后，网站会自动更新。

三维渲染使用 three.js，许可证见 [THREE-LICENSE.txt](assets/THREE-LICENSE.txt)；Natural Earth 地理数据为 public domain，其他素材来源见数据说明。

### 亚洲台风示意图

主导航按“地球模拟 → 台风结构 → 台风示意图 → 知识挑战”排列。`diagram.html` 展示原创中文亚洲台风路径图，支持打开高清 SVG。真实海岸线来自本地 Natural Earth；路径、副高和阶段均为教学示意，没有虚构观测日期或风速。运行 `python3 scripts/build-diagram.py` 可重新生成图稿。
