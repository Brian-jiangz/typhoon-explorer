# 台风探秘 · 地球实验室

一个可以直接在浏览器里玩的中文台风科普网站。

**在线体验：https://brian-jiangz.github.io/typhoon-explorer/**

## 可以玩什么

- **怎么形成**：点击海面选择起点，设置云团强弱、海水、湿度与上下层风差，让云团逐步移动、增强或减弱；支持暂停、回看与重新开始。九项影响条件直接展开，右侧风暴详情及图层开关始终可见；北上后按示意环境逐渐变凉、增加上下层风差，当前位置的条件同步显示。
- **往哪儿走**：在三维地球上观察台风云系与路径，分别调整副高的西伸程度和脊线南北位置。
- **台风结构**：旋转、俯视或剖开示意云系，认识风眼、眼墙、雨带与高空流出。
- **知识挑战**：找眼墙、摆副高、判断暂时平静与准备防台风用品，共四个可反复尝试的任务。

## 使用方式

打开上面的在线链接即可。也可以下载仓库，直接打开 `index.html`；资源均保存在本地，无须 API 密钥或额外构建。三维效果需要浏览器支持 WebGL，结构页提供平面备用视图。

## 演示范围

地球采用真实地表合成影像，云系、引导风和台风强度属于理想化科普演示。副高实验使用理想化高度场、地转近似和球面距离换算；没有接入实时天气，也没有经过历史台风路径校准。图上的路线和触岸区域不用于天气预报或避险决策。实际防台风行动请遵循当地官方预警与安排。

方法、数据和外部资源说明见 [数据与模型说明](assets/SOURCES.md) 及 [结构与挑战依据](assets/LEARNING-SOURCES.md)。

## 检查与发布

运行 `node checks/verify-formation.cjs` 可检查选点、逐步生长、衰减与记录回看；运行 `node checks/verify-ridge.cjs` 可复查引导方向、单位换算、控制独立性、路径积分和陆上衰减的一致性。这些检查不代表真实预报精度。

GitHub Pages 从 `main` 分支根目录发布。后续推送到 `main` 后，网站会自动更新。

三维渲染使用 three.js，许可证见 [THREE-LICENSE.txt](assets/THREE-LICENSE.txt)；Natural Earth 地理数据为 public domain，其他素材来源见数据说明。
