# 台风探秘 · 地球实验室

一个可以直接在浏览器里玩的中文台风科普网站。

**在线体验：https://brian-jiangz.github.io/typhoon-explorer/**

## 可以玩什么

- **热带气旋实验**：支持北半球多海域，可通过“大西洋”“美国附近”等入口转地球并轻点海面；在同一块面板选择海面起点、初始云团、月份及环境条件，并拖动或用按钮摆放副高。选好海面起点后即可开始，无需额外勾选副高确认。开始前可调整副高；开始后隐藏地球上的两个副高操作文字框，保留副高轮廓。开始后锁定全部实验设定，暂停、回看、重播不解锁；点击“重新设置”清除记录并重新开放选点与条件。初始观察窗口为 15 天，窗口末尾可点击继续观察，每次延长 5 天；不强制登陆或消散，缺测会单独说明停止原因。进度条以观察窗口为范围，只能回看已计算部分。九项条件直接展开，右侧详情与图层始终可见。
- **知识挑战**：找眼墙、摆副高、判断暂时平静与准备防台风用品，共四个可反复尝试的任务。

## 使用方式

打开上面的在线链接即可。也可以下载仓库，直接打开 `index.html`；资源均保存在本地，无须 API 密钥或额外构建。三维效果需要浏览器支持 WebGL；知识挑战使用平面示意图。

## 数据与科学边界

台风实验默认读取 NOAA ERSSTv5 和 NCEP–NCAR 再分析的 1991–2020 月平均气候背景，并以 tcpyPI / BE02 温湿剖面算法计算热力强度上限。可切换月份，沿途海温、700 hPa 湿度、200–850 hPa 风差和引导风随位置变化；不再用纬度单独决定降温。手动修改会标为假设试验。

热力上限有公开物理依据；组织度、增长/衰减时间尺度、暖水深度敏感性及气压估算仍是未校准的简化关系，没有完成历史台风回报验证。主实验在气候引导风上叠加用户调整副高的理想化扰动；挑战页仍使用独立的理想化副高及示例生命周期。三维云系仍为视觉示意，地表是静态合成影像。网站不能预测真实台风或实际登陆位置。

方法、输入文件校验和及软件版本见 [数据与模型说明](assets/SOURCES.md)、[数据清单](assets/climate-manifest.json) 和 [知识挑战依据](assets/LEARNING-SOURCES.md)。背景重建脚本为 [scripts/build-climate.py](scripts/build-climate.py)，需要 NumPy、xarray、netCDF4 和 tcpypi==1.4；网页运行不需要这些依赖或 API 密钥。

## 检查与发布

运行 `node checks/verify-formation.cjs` 可检查选点、逐步生长、衰减与记录回看；运行 `node checks/verify-ridge.cjs` 可复查引导方向、单位换算、控制独立性、路径积分和陆上衰减的一致性。有原始缓存和上述 Python 依赖时，还可以运行 `python scripts/verify-climate.py --cache <原始资料目录>` 独立复查温湿单位、PI 和引导风积分。这些检查不代表真实预报精度。

交互流程检查为 `checks/verify-setup.cjs` 与 `checks/verify-quiz.cjs`，需要 Node.js 和 `linkedom`（可由外部测试环境提供）。它们覆盖统一设置、开始门槛、运行锁定、重新设置与四项知识挑战，使用模拟渲染器，不替代实际浏览器的视觉检查。

GitHub Pages 从 `main` 分支根目录发布。后续推送到 `main` 后，网站会自动更新。

三维渲染使用 three.js，许可证见 [THREE-LICENSE.txt](assets/THREE-LICENSE.txt)；Natural Earth 地理数据为 public domain，其他素材来源见数据说明。
