# 杜苏芮（2023）历史天气检验

此入口用一个登陆中国大陆的历史案例，检验原有月平均引导过慢的问题。全球自由选点、副高手动调整仍在“多年平均沙盘”中。历史案例采用原始天气场，副高不能手动调整；点击开始后，初始条件锁定，需“重新设置”才能更改。

## 数据

- [NOAA NCEP–NCAR Reanalysis 1](https://psl.noaa.gov/data/gridded/data.ncep.reanalysis.html)：2023 年六小时 u/v 风、温度、相对湿度、位势高度和海平面气压。原始 2.5° 网格，范围 0–45°N、100–160°E，打包时间 2023-07-21 00 UTC 至 07-31 00 UTC（0–240 h）。风和热力环境均随位置、日期变化。
- [NOAA OISST v2 high resolution](https://psl.noaa.gov/data/gridded/data.noaa.oisst.v2.highres.html)：每日海温；原始产品为 0.25°，本案例 NCSS 子集按十格取样，实际使用约 2.5°，不宣称保留原始高分辨率。先作海陆掩膜感知空间插值，有效权重至少 0.5；每日值赋给该 UTC 日的六小时快照，网页对快照作时间线性插值，日界附近有六小时过渡。
- [JMA RSMC Tokyo 最佳路径](https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/besttrack.html)：2305 DOKSURI，[完整官方 ZIP](https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/Besttracks/bst_all.zip)，修订日期 20231025。[记录格式](https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/Besttracks/e_format_bst.html)。从首个热带风暴时刻 2023-07-21 00 UTC 开始，13.8°N、133.0°E、35 kt（18.00554 m/s）。JMA 风速为十分钟平均，不能与其他平均时长的强度直接等同。
- [中国气象局公布的登陆时间](https://www.cma.gov.cn/ztbd/2023zt/2023tf/20230725/2018070910/202307/t20230728_5680547.html)：2023 年 7 月 28 日 09:55 北京时间，福建晋江。

每个 NCSS 请求 URL、原始文件 SHA256、单位、抽查剖面和打包文件 SHA256 均保存于 [weather-manifest.json](weather-manifest.json)。原始 NetCDF 在构建者外部缓存，仓库只分发静态打包资料。

## 计算与副高

主方案取 850–200 hPa 各层风的压力加权平均，在空间、六小时时间之间线性插值，以 0.25 h 中点法积分，球半径 6371 km。图上箭头和路径调用相同风场；没有速度倍增、β 漂移、最佳路径牵引、未来位置插值或强制登陆，也不随模拟强度切换引导层。最佳路径仅显示和评分，不参与后续轨迹积分。初始位置和风速取自 JMA；其余组织参数仍为教学设定。

金色实线为 500 hPa 的 5880 m 位势高度等高线，金色虚线为 5860 m，分片线性取交点并随时间更新。它们不是以手工椭圆替代的实况；也不能将区域内每段高度线都解释为西太平洋副高，更未自动诊断副高中心、脊线及独立高压系统。历史模式保留真实天气场，禁用手动重排副高。

潜在强度仍由 BE02/tcpyPI 1.4 根据同一时刻海温、海平面气压及大气温湿剖面计算，参数同月平均沙盘。六小时温度源单位是 K，转 ℃；海平面气压源单位 Pa，转 hPa；混合比单位 g/kg。700 hPa 湿度、200–850 hPa 切变逐时空取样。暖水深度等仍为假设；未接入真实海洋剖面。增强、衰减、气压和程序云图不等同于观测，其精度未在本次检验。近岸热力缺测时保留已有海上强度但继续按有效风场移动；风缺测或越过资料范围停止。

## 同起点对照

统计 JMA 六小时时刻 0–228 h 的球面位置误差；平均移速为前 120 h 的总路径长 / 120 h。三方案无参数拟合，初始时刻和位置相同。

| 方案 | 平均位置误差 | 前五天平均移速 | 相对 CMA 登陆时间 |
|---|---:|---:|---:|
| 原有 1991–2020 年 7 月平均背景 | 588 km | 9.2 km/h | 228 h 内未抵达大陆 |
| 六小时局地深层引导（主方案） | 116 km | 17.9 km/h | 提前 5.7 h |
| 六小时 300–800 km 环带风（敏感性） | 265 km | 11.9 km/h | 提前 11.4 h |
| JMA 最佳路径 | — | 12.1 km/h | 与粗海岸线相交约为 7月28日10:00 北京时间 |

环带风只做敏感性：对网格中心 300–800 km 范围作 cos(latitude) 面积权重平均后再插值。环带速度较接近，但路径与登陆更差，故不以“速度更接近”宣称整体更准确。主方案相对月平均背景显著改善位置和登陆，但前五天速度仍偏高约 49%。

登陆判定用 Natural Earth 1:110m 陆地多边形中包含北京的欧亚大陆部分，并限定 20–40°N、105–123°E，以排除中国台湾省岛屿及海南。每 0.25 h 检测首次相交。主方案结果为 7月28日04:15 北京时间，约 24.76°N、118.79°E；JMA 轨迹按同样掩膜、同样步长约 10:00 与海岸相交。两者交点相距约 26 km，但粗海岸线、时间采样和 2.5° 风场无法支持“已验证 26 km 精度”的结论。CMA 的真实登陆时间与粗掩膜交点时间分开记录于 [完整结果](weather-validation.json)。

这是一个**事后再分析、单案例路径检验**。再分析包含风暴信息，不是独立天气预报。尚未独立验证其他台风、其他月份/海盆、强度演变及生成概率；不应推广为普遍精度。默认案例可在资料区内换起点或改环境；右侧预计算评分明确只适用于未修改的标准案例，不为自选实验打分。

## 再现与检查

构建依赖 Python、requests、NumPy、xarray/netCDF4、tcpypi==1.4；独立验证另需 SciPy。网页运行只需要本地静态资源，无 API 密钥。

```
python scripts/build-weather.py --cache <原始资料缓存>
node scripts/validate-weather.cjs
python scripts/verify-weather.py --cache <原始资料缓存>
node checks/verify-weather.cjs
node checks/verify-weather-ui.cjs
```

最后一项需要外部提供 linkedom，并使用真实 Three.js 数学对象和模拟渲染器，不能替代真实 WebGL 视觉检查。独立 Python 检查直接读取未经四舍五入的原始 NetCDF，以 SciPy 插值并重新积分；24/72/120/168/228 h 的位置均与网页方案相差小于 1 km。此检查验证数据打包和程序一致性，不代表真实台风误差小于 1 km。
